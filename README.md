# BookBot
A simple Python tool for analyzing the contents of text files.

## Description
BookBot is my first project from [Boot.dev](https://boot.dev). It’s a backend application that reads a directory of books, counts every word, and calculates how many times each character appears. 

## Features
* **Word Counter:** Quickly scans documents to find the total word count.
* **Character Analysis:** Breaks down every character found and sorts them by frequency.
* **Automated Reporting:** Generates a clean, readable report of the results in the terminal.

## How to Run
1. Clone the repo.
2. Ensure you have Python installed.
3. Run the program:
   ```bash
   python3 main.py
   ```
